# Level 1 美术素材替换说明

游戏里现在的画面都是代码生成的初期版本。把正式美术文件放进这个文件夹，并在 `manifest.json` 里填上文件名，游戏就会自动换用。**没填的继续用内置版本**，所以可以一张一张地换。

## 怎么替换

1. 把文件放进 `assets/level1/`（可以建子文件夹，比如 `textures/`）。
2. 打开 `manifest.json`，在对应的位置填上文件名。例如：
   ```json
   "lane_0_normal": "textures/lane_0_normal.png",
   ```
   留空 `""` 就是继续用内置版本。
3. 在 http://localhost:8080 按 **Ctrl+F5** 刷新，就能看到效果。
4. 按 F12 打开控制台，每替换成功一项会显示 `[美术素材] 已替换 …`；文件名写错或文件坏了会显示 `替换失败`，游戏照常运行，只是那一项还用内置版本。

`reference/` 文件夹里是**现在游戏里用的版本**（贴图 PNG + 赛车参考模型），可以直接当模板对照尺寸和朝向。

## 通用规则

- 图片用 **PNG**（需要透明时）或 **JPG**（大背景图），sRGB 颜色。
- 游戏有辉光效果：**越亮的颜色越会发光**。想要发光的部分画亮，不想发光的部分保持暗。
- 建议出 2 倍或 4 倍尺寸（比如 128×256 的出 256×512 或 512×1024），**长宽比例保持一致**。

|---|---|---|---|

| `lane_1_boost` | 128×256 | 加速赛道 | 同上，箭头要朝**上**（= 前进方向） |
| `lane_2_slow` | 128×256 | 减速赛道 | 同上 |
| `lane_3_obstacle` | 128×256 | 有障碍墙的赛道 | 同上 |
| `lane_4_short` | 128×256 | 短台 | 同上 |
| `lane_5_crumble` | 128×256 | 碎裂赛道（踩上去会塌） | 同上 |
| `lane_6_bounce` | 128×256 | 弹射赛道 | 同上 |
| `wall_hazard` | 64×64 | 障碍墙表面 | 可无缝平铺，横向会重复 3 次 |
| `finish_checker` | 128×128 | 终点那一节所有赛道 | 可无缝平铺，每 4 米重复一次 |
| `star_particle` | 64×64 | 星空里的星星 + 所有火花、爆炸粒子 | **白色、透明背景**，游戏里会自动染色 |
| `shockwave` | 正方形 | 连跳时脚下扩散的冲击波圆环 | **白色、透明背景**的圆环，圆心在图片中心，环的外沿接近图片边缘 |

**赛道贴图规则**
- 图片**左右两边对应赛道的两侧**，图片**从下往上是车前进的方向**。
- 沿赛道方向每 16 米重复一次，所以**上下边缘要能无缝衔接**。
- 贴图同时当发光图用：**底色要暗**，边线、图案画亮会发光。
- 每条赛道两端那条细发光条的颜色由代码控制（普通 #3aa8ff、加速 #00fff0、减速 #b04dff、障碍 #ff3355、短台 #ffd23a、碎裂 #ff8a1f、弹射 #3dff8a）。想改颜色告诉程序。
- 赛道类型要能一眼分清，玩家在高速下靠颜色和图案判断走哪条。

## 二、宇宙背景

| 名称 | 要求 |
|---|---|
| `sky` | **2:1 全景图**（等距柱状投影），建议 4096×2048 或 8192×4096，JPG。会替换掉星云。 |
| `hideProceduralStars` | 填 `true` 会关掉代码生成的星星（全景图里自己画了星星时用），默认 `false` |
| `planet_1` | 蓝色带环大行星的表面贴图，**2:1**（如 2048×1024） |
| `planet_1_ring` | 大行星的环：**正方形透明 PNG**，从正上方看整个环，圆心在图片中心，环外沿接近图片边缘 |
| `planet_2` | 粉红中行星表面贴图，2:1 |
| `planet_3` | 橙色小行星表面贴图，2:1 |

行星会受太阳光照，背光面会变暗。如果打算把行星直接画进全景图，就不用填行星这几项。

## 三、赛车模型

| 名称 | 要求 |
|---|---|
| `car.model` | **.glb** 文件（glTF 二进制，贴图打包在里面） |
| `car.length` | 可选：车长（米）。填了会按包围盒自动缩放到这个长度，并把车底中心对齐到原点，适合尺寸和原点不规范的模型 |
| `car.rotateY` | 可选：绕竖直轴旋转的角度。模型车头朝 -Z 时填 `180` |
| `car.scale` | 整体缩放，默认 `1`。模型尺寸不对时可以先用这个微调 |

- **朝向**：车头朝 **+Z**，车顶朝 **+Y**；原点在**车底中心**。
- **尺寸**（单位：米，和参考模型一致）：宽约 2.8（含尾翼），高约 1.2，长约 4.0。参考 `reference/car_reference.glb`。
- **尾焰位置**：在模型里放两个空节点，命名为 `nozzle_L` 和 `nozzle_R`，放在两个喷口的位置，拖尾就会从这里喷出。没有这两个节点就用默认位置（车尾两侧）。
- 材质用 glTF 标准的 PBR 材质（金属度 / 粗糙度）。需要发光的部位（灯、霓虹条、喷口）用自发光（Emissive）。
- 建议面数 5 万三角面以内，贴图单张不超过 2048×2048。
- 车底的蓝色悬浮光由游戏代码提供，会保留。

## 四、界面

| 名称 | 要求 |
|---|---|
| `ui.logo` | 菜单上的游戏标题，**透明 PNG**（或 SVG），建议宽 1040 左右，显示时最大宽 520、高 180 |
| `ui.favicon` | 浏览器标签页图标，**512×512 PNG** |
